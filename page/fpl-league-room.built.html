      One Python file, nothing to install. Needs Python 3.9 or newer.

      Run it
      In a terminal, in the folder with the script. Your league id is the number in the league's address on the FPL site, and it changes every season.
      python3 fpl_fetch.py 123456
      On Windows use py. Best on Tuesday morning, once Monday's bonus points are final.
